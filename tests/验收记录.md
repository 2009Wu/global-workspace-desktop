# Windows 0.1.0 验收

2026-11-22 在本机 Windows x64 上执行。基于当前源码构建隔离身份的 0.1.0 和 0.1.1，通过回环 HTTP 服务模拟 GitHub 正式版发现和附件下载。测试打开真实安装程序和 WebView2 窗口，点击界面控件，并通过 Windows 系统保存对话框写入导出文件。

- 首装无 Release 时显示主窗口；同版和预发布无更新卡。
- 已打开七种图层，均收到至少一个可读记录。打开独立事件详情窗并确认存在来源入口。
- 检查语言下拉共 21 项，切换英文、阿拉伯文、日文、简体与繁体中文；验证 RTL 和语言保存。
- 关闭右下角卡片后可从设置更新。下载损坏 ZIP 时仍停留在旧版，同一按钮允许重试。
- 强制结束更新进程，故障发生在活动版本切换后、新版界面确认前。从改过名字的快捷方式启动，恢复到旧版。
- 两个真实窗口同时请求更新，只下载一份 ZIP。原生「另存为」保持打开期间，更新停在等待阶段。导出完成并校验 JSON 内容后才重启。
- 新版窗口自动打开；旧版收藏能再次打开，界面语言保留，桌面入口只剩一个且名称未变。
- 测试版在代理不可达、更新服务停止时通过改名的快捷方式重新启动，可查看已有收藏和此前缓存的记录。
- 对交付 ZIP 运行额外的 12 个拒绝用例，覆盖错产品、错版本、逐文件摘要、未列文件、重复和非法 Windows 路径。

受个人凭据限制的 X、Flightradar24、Datalastic 没有使用付费账户端到端验证。卫星影像、新闻照片与视频的可用性由来源和网络决定。二十种语言已配置，尚未逐语进行母语人工审校。这次验收覆盖本机，未覆盖干净 Windows 10 虚拟机。

## 0.1.2 地图验收

在 Windows WebView2 主窗口中检查北京与纽约，确认中文道路和英文道路名称实际进入画布绘制。城市视图加载区县标注，地图可放大至 19 级。阻断街道服务并移至新城市后，区县标注保留，点击重试后恢复在线矢量图。

从地图点击有坐标的测试观测记录，核对弹窗的来源坐标与标记一致。核对区域参考记录与缺少位置的记录均有相应说明。按公布坐标检查钓鱼岛、黄尾屿、赤尾屿命中中国及其子区域，另验主岛与赤尾屿不命中日本。海面和邻近岛屿测试点未被纳入子区域。

同一源码通过上述真实窗口更新回归。正式 0.1.2 包通过 12 项清单和路径拒绝测试。

## 0.1.3 卫星地图验收

Windows WebView2 测试载入北京 18 级和纽约 19 级高清影像，检查影像像素、道路名称、区县标注和透明标注图层。点击测试卫星事件后，弹窗经度与来源一致。在高清模式下选择钓鱼岛子区域，主岛坐标命中筛选。

切换到 NASA 按日观测，实际加载所选日期的影像。模拟单块高清影像缺失，逐像素核对回退影像与上一级对应象限。阻断高清影像服务后，界面显示重试，解除阻断并点击重试后重新加载。正式 0.1.3 包通过 12 项清单和路径拒绝测试。

## 0.1.4 冲突报道与详情验收

在主窗口切换八个图层，核对联合国、国际危机组织及 IMF PortWatch 返回的记录。通过海峡专题打开两周逐日航次数表，切换简体、英语与繁体，核对列表、详情标题和保留的来源原文。对埃及阿语和尼日利亚皮钦语另做实际翻译调用。

以 BBC 芬兰湾报道打开详情，验证海域代表点、中文摘要、发布者署名、附加摘录、原文入口以及另一窗口切换语言后的同步。用波克罗夫斯克及中文别名核对城市定位，另检查只提到发言国的标题不会生成该国的事件点。详情窗没有加载 Leaflet 或全球几何文件。预备阅读窗口完成后，本机一次从点击到详情控件可读为约 0.21 秒；发布者补充资料随后到达。

重现方法见根目录 README 和本目录下的 update-e2e.mjs、PackageChecks.ps1。
